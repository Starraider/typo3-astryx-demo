============
TYPO3 Astryx
============

TYPO3 Astryx is a modern TYPO3 content element and layout foundation designed to replace
``typo3/cms-fluid-styled-content`` (FSC). It provides responsive Content Blocks, native
Fluid components, multi-column containers, and design tokens styled with **StyleX**.

Astryx follows strict progressive enhancement: editorial pages render with clean,
semantic HTML5 and atomic CSS, needing zero frontend JavaScript for the standard reading
experience. Optional client-side controllers enhance interactions such as modal navigation,
accordion height transitions, and carousel scroll snapping without trapping keyboard
or screen reader users.
